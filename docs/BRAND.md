# HARDWOOD — brand system for the two-product set

**The house:** HARDWOOD — an agent skills program. (The hardwood is where practice becomes
games and stats become real. Receipts live on the court, not in the press conference.)

## The set — two products, one game
| | muscle-memory | Skill Plus-Minus (SPM) |
|---|---|---|
| Role | **The training system** — the player | **The officiating crew** — the referee |
| One-liner | *Every session is practice film.* | *Every skill gets a box score.* |
| What it does | Watches real work, distills recurring lessons into skills, improves them, prunes what doesn't earn minutes | Twin-agent trials + placebo + prereg rules → an honest number on what any skill is worth |
| Ships as | `npm:@letta-ai/muscle-memory` (Letta mod) | referee harness + verdict engine (separate repo — the ref never plays for the team) |
| Color | court-orange `#ff6b35` | whistle-teal `#5eead4` |

**Set tagline:** `Train hard. Keep score.`
**Long form:** *The first agent skill system where the learning is autonomous and the stats are real.*

## Voice rules (the same ones that won the ring)
1. **Restraint is the flex** — quiet headline, loud receipts. Never a claim without its n.
2. Basketball vocabulary is structural, not decorative: practice film, box score, plus-minus,
   the whistle, earning minutes, tenure, the bench. If a metaphor doesn't map to a real
   mechanism, it doesn't ship.
3. The failures are marketing: BLOCKED runs, culled drills, capped labels — shown proudly.
4. Every number on any surface must trace to a commit hash. "ball don't lie" = the sign-off.

## Separation doctrine (brand-level, because it's architecture-level)
The referee is never bundled into the player's jersey. MM learns; SPM judges; only receipts
cross. Marketing must never imply MM grades itself.

## Naming conventions
- Releases: v0.7 "The Routing Release" · v0.8 "The Referee Release" · v0.9 "The Transfer
  Release" · v1.0 "The Proof". Pattern: "The ___ Release", one job per release.
- Verdicts (SPM, user-facing): helped / hurt / neutral / directional / insufficient / blocked.
- The lifecycle ladder: staged → active → tenured → pinned (minutes are earned, not granted).

## Vetoable alternatives considered (for Adrian/Kev)

it-counts meaning. Set taglines: "Practice makes skills. The referee makes them count." /
"Skills earned, not granted." — both kept as secondary lines.
